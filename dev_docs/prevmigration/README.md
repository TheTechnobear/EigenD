# Previous Migration Documentation

This directory contains documentation from a previous Python 3 migration attempt by TheTechnobear. These files are retained for reference and historical context.

## Files

- `dev_howitworks.md` - System architecture and development patterns
- `dev_notes.md` - Migration progress and technical notes
- `dev_todo.md` - Previous task tracking and priorities

## Note

The current migration effort uses the files in the parent `dev_docs/` directory with the `copilot-` prefix. These legacy files provide useful background information but are not actively maintained.
